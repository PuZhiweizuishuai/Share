## 移动端文件卡片操作按钮适配（web_v2/share_v3）

- 问题：移动端窄屏下 `views/file-list.vue` 与 `components/file-search-list.vue` 的文件操作按钮（预览/下载/分享/重命名/删除，4-5 个图标按钮）与文件名/元信息挤在同一 flex 行，`.file-info` 因 `min-width:0` 被压缩到几乎无空间，导致文件名截断严重、按钮与文本重叠。
- 原因：file-list 旧移动端用 `margin-left:auto`，按钮"刚好能挤下"时不换行继续挤压，"挤不下"时才换行，行为不确定；file-search-list 完全没有操作按钮的移动端适配。
- 方案：在 `@media (max-width:600px)` 内将 `.file-item` 设为 `flex-wrap:wrap`，并给 `.file-actions` 设 `flex:1 1 100%`，强制操作按钮独占第二行（全宽、`justify-content:flex-end` 靠右、上方加 `border-top` 分隔线）。第一行只剩 icon + file-info，文件名/元信息获得整行宽度，不再被挤压重叠。
- 桌面端（>600px）布局完全未动，所有改动均封装在移动端媒体查询内。
